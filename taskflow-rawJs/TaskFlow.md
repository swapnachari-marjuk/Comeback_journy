# 🚀 TaskFlow - Advanced Vanilla JS Todo App

TaskFlow is a high-performance, lightweight Task Management application built with pure JavaScript. This project focuses on DOM optimization, State Management, and clean architectural patterns.


## 🛠️ Tech Stack
- **Core:** JavaScript (ES6+)
- **Styling:** Tailwind CSS
- **Storage:** LocalStorage API

## ✨ Key Features
- **Persistent Data:** Tasks remain saved even after page refresh using LocalStorage.
- **Event Delegation:** Optimized event handling for better memory management.
- **Performance Optimized:** Uses `DocumentFragment` for fast DOM rendering.
- **Dynamic Filtering:** Filter tasks by *All*, *Active*, and *Completed* status.
- **Task Count:** Real-time tracking of pending tasks.
- **Bulk Action:** Clear all completed tasks with a single click.

## 🚀 Future Roadmap (Upcoming Features)
